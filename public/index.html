首次使用？安装 PAW 与连接服务
  1. 安装 Python 3.10 或更新版本，在终端运行：
    python -m pip install programasweights --extra-index-url https://pypi.programasweights.com/simple/
  2. 下载译间 PAW 连接脚本，在脚本所在文件夹运行：
    python paw-bridge.py
  3. 保持终端运行，点击「检测部署状态」，再点击「加载并验证模型」。首次约下载 620MB 资源，可能需要几分钟；就绪后即可改写。

浏览器无法直接检查已安装的软件。此脚本将网页连接到官方 PAW 程序；检测只检查服务，验证会运行一句固定示例。

在局域网另一台电脑部署（Windows PowerShell）
$env:YIJIAN_PAW_KEY="替换为你自己的服务密钥"
python paw-bridge.py --host 0.0.0.0

填入那台电脑的地址（例如 http://192.168.1.100:8766）及相同密钥，并允许防火墙的专用网络访问。不要将服务暴露到公网。127.0.0.1 始终指当前浏览器所在设备。

默认允许本站来源 https://wang-kaijun.github.io；其他部署地址启动时添加 --origin https://你的网页域名。按浏览器提示允许本地网络访问。如无法连接，检查服务、地址和跨域设置，或使用官方云端。

支持 CPU 运行。NVIDIA 显卡加速需要带 CUDA 的 llama-cpp-python；安装成功不代表已启用 GPU。官方安装说明 ↗

使用所选模型执行 Claudish 改写规则；效果可能与原版 PAW 不同。模型在下方设置，可复用全局保存的站点。

全局模型

在这里配置共用模型，由各功能分别决定是否使用。

各功能独立选择

站点地址、模型列表和密钥只需配置一次。各功能可选用已保存站点中的不同模型，或开启「使用全局模型」。De-Claudish 的此设置仅对「自选大模型」生效。

本地模型安装与连接说明
  1. 从 Ollama 官网安装并下载适合设备的模型。
  2. 设置环境变量 OLLAMA_ORIGINS=https://wang-kaijun.github.io，重启 Ollama。
  3. 选择「本地 / 局域网模型」，填写 http://127.0.0.1:11434/v1，点击获取模型列表并测试连接。

局域网另一台电脑需配置监听地址（如 OLLAMA_HOST=0.0.0.0:11434）并允许专用网络防火墙访问，网页填写其局域网 IP。其他服务需提供 OpenAI 兼容接口，例如 http://192.168.1.100:8080/v1。

此选项提供安装引导，网页不会替你安装软件。浏览器可能请求本地网络权限；服务还需允许跨域访问。
